# Code paths not yet run on a GPU

No GPU is available during development, and no GPU test result has been recorded here yet, so every code path below
is unverified. An entry is removed only when a cluster result that covers it is reported. `benchmark/gpu.slurm` runs
the GPU tests (`TEST_ARCHITECTURE=GPU TEST_GROUP=all`) and `benchmark/benchmark.jl GPU`.

Citations of Oceananigans and Oceanostics refer to Oceananigans 0.116.1 and Oceanostics v0.21.7.

## 2. Array operations of the `Sorting` reference state

arrays. Each operation is cited where Oceanostics v0.21.7 (`src/BackgroundPotentialEnergyEquation.jl`, BPE below) or
Oceananigans 0.116.1 applies it to arrays on the model's architecture. The operations themselves are CUDA.jl's
(`sortperm!`, the scans and the reduction) or GPUArrays' (broadcasts, gathers and scatters through an index array).
The 4³ comparison tests reach each of them, but not at the sizes where a device sort or scan takes its multi-block
path; the benchmark reaches those sizes without checking values.
